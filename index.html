「ユニット造形システムを用いた視覚障害者向け立体感知能力向上プログラムの研究開発」

概要

視覚障害者の教育および概念形成においては、触覚、聴覚など他感覚による代替と情報の次元という考え方が重要です。点字は6点の2次元パターンで1次元の文字情報を表現しており、触図は2次元の図的表現による実物や概念の写しです。しかし、3次元の立体触察ツールは、教材用実物模型の他、博物館展示品等などに限られているのが現状です。

造形作家の松尾光伸は、白銀比等の幾何学的構成原理に基づくオリジナルな多面体ブロックの組み合わせによる「情報造形：INFORMART」を提唱し、触ってわかる触形譜等の支援ツールを開発してきました。

本研究では、1次元の点字、2次元の触図に続く3次元の触形として、視覚障害者のための造形教育・幾何学教育をはじめ保健医療分野にも寄与する社会実装ツールの開発を目標としています。

This project aims to develop a tactile art and therapy program for people with visual impairments and the elderly, using innovative unit-based modeling systems.

「触形プログラム」の主なユニット

楕円ユニット
45度楕円筒を斜め45度にカットした断面に正円と楕円を持つユニット。わずか2〜4個の同型パーツで膨大な造形パターンが産み出せます。
フィギュアーズユニット
人の佇まいやシルエットを表現するために設計されたユニットです。
ハートキューブ
立方体の6面を三つの楕円筒で繰り抜いた3等分割ユニット。パーツの組み合わせによってハートが現れます。
斜キューブ1/4
天面の1/4の正方形面と底面の同型面を斜めに結んで、立方体を等形4分割されたユニットです。
